# tensor-core-gemv Delta Specification

## Purpose

Accelerates quantized matrix-vector multiplication (`gemm_q4k_kernel` and `gemm_q6k_kernel`) using Ampere Tensor Core `mma.sync` instructions on NVIDIA RTX 3060 Mobile hardware.

## Requirements

### Requirement: Warp-Level Matrix Multiply-Accumulate
The CUDA compute subsystem SHALL provide `gemm_q4k_mma_kernel` utilizing inline PTX `mma.sync.aligned.m16n8k32` for quantized matrix-vector multiplication.

#### Scenario: Single token decode step on Q4_K model
- **WHEN** executing a linear projection (e.g., $W_q, W_k, W_v, W_o, W_{\text{down}}$)
- **THEN** weights and quantized activations are processed by hardware Tensor Cores in chunks of 32 elements per instruction, achieving $>180\text{ tok/s}$ throughput on 1.5B models.

### Requirement: Numerical Parity with DP4A Reference
The MMA compute pipeline SHALL yield numerical output within floating-point tolerance ($\epsilon < 10^{-4}$) compared to the golden CPU reference dequantization.

#### Scenario: Golden parity check across 1024-dimensional layer
- **WHEN** comparing output vectors generated by `gemm_q4k_mma_kernel` vs CPU golden reference
- **THEN** maximum absolute difference does not exceed $10^{-4}$ and mean squared error is $< 10^{-7}$.
