# flash-decoding Delta Specification

## Purpose

Provides high-throughput Split-KV FlashDecoding attention kernels for accelerated multi-thousand token context windows.

## Requirements

### Requirement: Split-KV Parallel Attention Kernel
The CUDA kernel subsystem SHALL provide `flash_decoding_split_kernel` and `flash_decoding_reduce_kernel` to parallelize KV cache evaluation across multiple thread blocks on GPU SMs.

#### Scenario: Long-context decode step (N > 1024 tokens)
- **WHEN** evaluating single-token attention over a KV cache containing $>1024$ tokens
- **THEN** the sequence is partitioned into chunks of 256 tokens and evaluated concurrently across SMs, maintaining $<1.0\text{ ms}$ total attention latency.

### Requirement: Bit-Exact Parity with Online Softmax Reference
The FlashDecoding reduction kernel SHALL yield numerical output within floating-point tolerance ($\epsilon < 10^{-4}$) compared to standard single-pass PagedAttention.

#### Scenario: FlashDecoding parity check
- **WHEN** comparing output vectors generated by FlashDecoding vs standard PagedAttention
- **THEN** maximum absolute difference does not exceed $10^{-4}$.
